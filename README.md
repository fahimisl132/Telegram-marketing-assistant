# Telegram Group Finder

A Telegram bot that lets an admin select a country and describe the kind of public Telegram groups they want.
It uses:
- Telegram Bot API (python-telegram-bot) for the user interface.
- Telethon user session for Telegram's public/global search.
- SQLite for caching and deduplication.
- A transparent relevance scorer using group name, username, description and matched public posts.

## Important limitation

Telegram does not expose a complete directory of every public group to a bot. The user session can search Telegram's public/global search, but results depend on what Telegram makes discoverable.

The country filter is heuristic, not an official Telegram country field. It scores country names, language, domain hints and other public metadata. It cannot guarantee that a group physically belongs to a country.

The program does NOT access private groups, bypass permissions, or scrape private/member-only information.

## 1. Create credentials

### Bot token
Create a bot with @BotFather and copy its token.

### Telegram API ID / API hash
Create your own Telegram application at https://my.telegram.org and obtain:
- API ID
- API hash

Do not share these credentials publicly.

## 2. Install

Python 3.11 is pinned in the included Dockerfile for Railway compatibility.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in:
- BOT_TOKEN
- API_ID
- API_HASH
- ADMIN_IDS (comma-separated Telegram user IDs)

## 3. First run

```bash
python bot.py
```

The first run asks for the Telegram user account phone number and login code in the terminal. If two-step verification is enabled, it asks for the password.

A `finder.session` file is created. Keep it private.

## 4. Use

Open the bot:
1. Press Search groups.
2. Choose a country.
3. Enter a natural-language request, e.g.
   `freelancing and remote job groups for Bangladesh`
4. The bot performs several Telegram global searches, deduplicates results, scores them and returns the most relevant public groups.

## Ranking

The default score combines:
- name match
- username match
- description/about match
- public message/post match
- country evidence

The displayed percentage is a relevance score generated by this program, NOT an official Telegram score.

## Production notes

For a VPS:
- run with systemd or Docker
- use a dedicated Telegram account for the user session
- restrict the bot to admin IDs if this is a private utility
- back up `finder.db` and `finder.session` securely
- respect Telegram's Terms of Service and rate limits

## Scope

This project is deliberately limited to publicly discoverable information and does not attempt to enumerate private groups or evade Telegram access controls.


## Railway deployment

This project includes a Railway-compatible `Dockerfile` pinned to Python 3.11 and `railway.json`.
In Railway, deploy the project and add these Variables: `BOT_TOKEN`, `API_ID`, `API_HASH`, and `ADMIN_IDS`.
The SQLite database and Telethon session are stored under `/app/data`. Attach a Railway Volume mounted at `/app/data` if you want the database and Telegram login session to survive redeploys.

The bot uses the same asyncio loop for python-telegram-bot and Telethon and disables automatic loop closing during `run_polling`, which avoids the common `RuntimeError: Event loop is closed` shutdown crash on Railway.
